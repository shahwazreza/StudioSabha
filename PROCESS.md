# Process

**Chosen Agile model:** Extreme Programming (XP)

StudioSabha is being developed using XP. Work is tracked as a prioritized list of tasks on a GitHub Projects board linked to Issues in this repository. Development proceeds through short iterations with frequent stakeholder feedback, pair programming, and test-driven development, rather than fixed Scrum-style sprints.

## Board

Project board: `https://github.com/users/shahwazreza/projects/3`

Columns: `Backlog` → `In Progress` → `Done`

## Prioritized Task List

Tasks are ordered by priority (top = build first):

1. Set up artwork upload with images, title, medium, and price
2. Add availability status to each artwork (available, reserved, sold)
3. Build public gallery page to browse available artwork
4. Build custom commission request form
5. Build non-technical admin dashboard for managing artwork and orders
6. Build "see it on your wall" preview feature
7. Integrate secure online payment
8. Deploy to a custom `.com` domain

## Practices

- **Pair programming** on core features to maintain code quality
- **Test-driven development**, especially for inventory and payment logic
- **Frequent stakeholder check-ins** with Sabha to review working increments and reprioritize as needed
