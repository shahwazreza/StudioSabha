# StudioSabha
 
A custom e-commerce website built for independent artist **Sabha** to showcase her artwork, manage inventory, sell pieces directly online, and accept custom commission requests.
 
## About
 
My cousin contacted me to create a for her where she can showcase her art, and potentially sell them.
We are calling it StudioSabha. Sabha is the name of my cousin. StudioSabha is a custom e-commerce website built for an independent artist (Sabha) to sell her work directly online. We may use Next.js with Supabase backend for data and authentication and we are thinking about adding Square API (not sure yet) for payment processing, with features like inventory, commission request form, a non-technical admin dashboard for managing artwork and orders (we may also use 3rd party integration for managing orders and inventory), "See how it looks on your wall" feature. At the end, we are going to get a .com domain and deploy it!
